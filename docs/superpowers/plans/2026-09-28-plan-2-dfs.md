# Plan 2: DFS — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a DFS page where students step through `DFS(G)` / `DFS_Visit(G, u)` exactly as on the lecture slides, see the call stack and discovery/retraction times, watch every edge get classified in real time (tree/back/forward/crossing), and answer predict questions about it.

**Architecture:** Plan 1 built the engine (graph model, trace of full per-line snapshots), the player, the panels and the BFS page. This plan first widens the shared contract (a `stack` data-structure view, a `choice` answer kind, per-step edge labels, validated settings). Then it adds the UI for those, then the DFS algorithm folder, then page and browser tests. Topological sort and SCC were dropped from v1 by staff decision (recorded in the spec).

**Tech Stack:** React 19, TypeScript 5.9, Vite 8, Vitest 5 + Testing Library (jsdom), Playwright.

**Spec:** `docs/superpowers/specs/2026-09-28-algo-visualizer-design.md`. Also read `docs/superpowers/plans/plan-1-followups.md`; this plan closes its "Plan 2" section.

## Global Constraints

- Pseudocode text is verbatim from the lecture slides, with the slides' line numbers (line number = array index + 1).
- Helper-procedure names are spelled as on the **rendered** slides: `DFS_Visit` (underscore). `pdftotext` drops the underscore, so do not copy names from it.
- Edge-type names are the lecture's: tree, back, forward, crossing (`Lectures/dfs.pdf`, "Four types of edges" and "Classification in real-time").
- Tie-breaking: the outer loop of `DFS` visits `G.V` in label order (natural comparison, `v1 < v2 < v10`). `G.Adj[u]` uses the displayed, reorderable adjacency order from `adjacency(g, u)`.
- Maximum 10 vertices per graph.
- A question on step `i` is shown over step `i − 1`. Step `i − 1` must let the student predict the answer without revealing it. Enforce this with `assertQuestionsPredictable` from `src/algorithms/testing.ts`.
- No backend. `localStorage` only for settings, every access wrapped in try/catch.
- `src/engine/` and `src/algorithms/*/run.ts` import nothing from React.
- UI language English. Styling uses CSS custom properties on `:root` with dark-mode overrides; the layout must not scroll horizontally at 375px.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

Inputs the spec implies that are most likely to bite a student. Each has a test in the task named.

1. The student toggles the lecture preset to undirected. DFS must run, label every edge exactly once, and use only tree/back (lecture lemma). Test in Task 3.
2. A directed 2-cycle (`a → b`, `b → a`). Both edges must get labels (tree, then back). Test in Task 3.
3. The student deletes everything but one vertex. DFS gives `d = 1`, `f = 2`, no edges and no crash. Test in Task 3.
4. A settings value in `localStorage` from an older version, or corrupted (for example `disabledTypes: null`), must not crash every page load. Test in Task 1.
5. A keyboard-only student answering an edge-type question: focus must land on the first option. Test in Task 2.

### Task 3: DFS algorithm

**Files:**
- Create: `src/algorithms/dfs/pseudocode.ts`, `src/algorithms/dfs/questions.ts`, `src/algorithms/dfs/presets.ts`, `src/algorithms/dfs/run.ts`, `src/algorithms/dfs/index.ts`
- Modify: `src/algorithms/registry.ts`
- Test: `src/algorithms/dfs/run.test.ts`

**Interfaces:**
- Consumes: `adjacency`, `edgeKey`, `moveInAdjacency`, `setDirected`, `vertexIds`, `Graph` (engine/graph); `Step`, `Question`, `Value`, `VertexState`, `treeEdgesFromPi` (engine/trace); `AlgorithmDef`, `Proc`, `Preset`; `assertValidTrace`, `assertQuestionsPredictable` (algorithms/testing).
- Produces: `dfs: AlgorithmDef` (id `'dfs'`, title `'Depth-First Search (DFS)'`), `runDfs(g: Graph): Step[]`, `ALGORITHMS = [bfs, dfs]`. Question types `dfs.discover`, `dfs.edgeType`, `dfs.finish`.

Sources of truth: pseudocode is `Lectures/dfs.pdf` slide 4 (rendered: `DFS(G)` and `DFS_Visit(G, u)`). The lecture preset is slide 5. Edge classification is the "Classification in real-time" slide:
- `v.color = white` → tree
- `gray` → back
- `black` with `u.d < v.d` → forward
- `black` with `u.d > v.d` → crossing

For undirected graphs, an edge is classified by the direction explored first; the second direction is not classified again.

**Step semantics:**
- Each emitted step shows the state **after** its line runs. `vars` holds the current frame (`u`, and `v` inside the loop) plus the global `time`.
- The DS view is the call stack, `['DFS(G)', 'DFS_Visit(G, v1)', …]`, bottom → top.
- Big steps are discovery (`DFS_Visit` line 2) and retraction (`DFS_Visit` line 10).
- An edge's label appears from its line-5 step onward.

**Questions** (each is shown over the previous step):
- `dfs.discover`, a vertex answer: "Which vertex will DFS discover next?" It is attached to the loop-header step that picks the white vertex: `DFS` line 5 for a new root, `DFS_Visit` line 4 for a neighbor. The previous step must show that vertex white and must not name it in `vars.u` or `vars.v`.
- `dfs.edgeType`, a choice answer: attached to the `DFS_Visit` line 5 step where an edge is classified for the first time. Options are `tree, back, forward, crossing` for directed graphs and `tree, back` for undirected graphs. The previous step has no label on that edge.
- `dfs.finish`, a number answer: "Lines 9–10: what value will u.f get?" It is attached to line 9. The previous step (line 8) still has `u.f` unset.

**Hand-verified expected results, lecture preset (slide 5), label order.** They match the slide's table exactly.
- d: v1 1, v2 2, v3 3, v4 4, v5 6, v6 11, v7 12, v8 13
- f: v1 10, v2 9, v3 8, v4 5, v5 7, v6 16, v7 15, v8 14
- π: v1 NIL, v2 v1, v3 v2, v4 v3, v5 v3, v6 NIL, v7 v6, v8 v7
- Edge labels:
  - tree (T): v1→v2, v2→v3, v3→v4, v3→v5, v6→v7, v7→v8
  - back (B): v5→v1, v8→v6
  - forward (F): v1→v3
  - crossing (C): v5→v4, v6→v2, v7→v1, v8→v5

With `Adj[v3]` reordered to `v5, v4`: v5 is discovered at 4, v4 at 5 with `v4.π = v5`, and v3→v4 becomes a **forward** edge.

**Undirected preset, hand-verified.** Edges a–b, a–c, b–d, c–d, d–e.
- d: a 1, b 2, d 3, c 4, e 6
- f: c 5, e 7, d 8, b 9, a 10
- π: a NIL, b a, d b, c d, e d
- Labels: a–b T, b–d T, c–d T, d–e T, a–c B

```ts
import { moveInAdjacency, setDirected, type Graph } from '../../engine/graph';
import type { Step } from '../../engine/trace';
import { assertQuestionsPredictable, assertValidTrace } from '../testing';
import { dfs } from './index';
import { runDfs } from './run';

const lecture = dfs.presets[0];
const undirected = dfs.presets[1];

const last = (steps: Step[]) => steps[steps.length - 1];
const attr = (steps: Step[], key: string) =>
  Object.fromEntries(Object.entries(last(steps).vertexState).map(([v, a]) => [v, a[key]]));

test('lecture example (slide 5): d, f and π match the slide table', () => {
  const steps = runDfs(lecture.graph);
  assertValidTrace(dfs, steps);
  expect(attr(steps, 'd')).toEqual({ v1: 1, v2: 2, v3: 3, v4: 4, v5: 6, v6: 11, v7: 12, v8: 13 });
  expect(attr(steps, 'f')).toEqual({ v1: 10, v2: 9, v3: 8, v4: 5, v5: 7, v6: 16, v7: 15, v8: 14 });
  expect(attr(steps, 'pi')).toEqual({ v1: null, v2: 'v1', v3: 'v2', v4: 'v3', v5: 'v3', v6: null, v7: 'v6', v8: 'v7' });
  expect(Object.values(attr(steps, 'color')).every((c) => c === 'black')).toBe(true);
  expect(last(steps).vars.time).toBe(16);
});

test('lecture example: every edge classified in real time', () => {
  expect(last(runDfs(lecture.graph)).edgeLabels).toEqual({
    'v1->v2': 'T', 'v2->v3': 'T', 'v3->v4': 'T', 'v3->v5': 'T', 'v6->v7': 'T', 'v7->v8': 'T',
    'v5->v1': 'B', 'v8->v6': 'B',

    'v5->v4': 'C', 'v6->v2': 'C', 'v7->v1': 'C', 'v8->v5': 'C',
```

```ts
import type { Question } from '../../engine/trace';

export type EdgeType = 'tree' | 'back' | 'forward' | 'crossing';
export const EDGE_LETTER: Record<EdgeType, string> = { tree: 'T', back: 'B', forward: 'F', crossing: 'C' };
export const EDGE_LEGEND = 'Edge types: T = tree, B = back, F = forward, C = crossing';

export const dfsQuestionTypes = [
  { type: 'dfs.discover', label: 'Which vertex is discovered next' },
  { type: 'dfs.edgeType', label: 'Type of each explored edge' },
  { type: 'dfs.finish', label: 'Value of u.f' },
];

export function discoverQuestion(v: string, explain: string): Question {
  return {
    type: 'dfs.discover',
    prompt: 'Which vertex will DFS discover next?',
    answer: { kind: 'vertex', value: v },
    explain,
  };
}

export function finishQuestion(u: string, t: number): Question {
  return {
    type: 'dfs.finish',
    prompt: `Lines 9–10: what value will ${u}.f get?`,
    answer: { kind: 'number', value: t },
    explain: `time was ${t - 1}; line 9 increments it to ${t} and line 10 sets ${u}.f = ${t}.`,
  };
}

export function edgeTypeQuestion(
  u: string, v: string, type: EdgeType, ud: number, vd: number | undefined, directed: boolean,
): Question {
  const why: Record<EdgeType, string> = {
    tree: `${v} is white, so ${v} is discovered from ${u}.`,
    back: `${v} is gray, so ${v} is an ancestor of ${u} that is still being explored.`,
    forward: `${v} is black and ${u}.d = ${ud} < ${v}.d = ${vd}, so ${v} is a descendant of ${u}.`,
    crossing: `${v} is black and ${u}.d = ${ud} > ${v}.d = ${vd}, so ${v} was retracted before ${u} was discovered.`,
  };
  return {
    type: 'dfs.edgeType',
    prompt: `Line 5 explores the edge (${u}, ${v}) for the first time. What type is it?`,
    answer: {
      kind: 'choice',
      value: type,
      options: directed ? ['tree', 'back', 'forward', 'crossing'] : ['tree', 'back'],
    },
    explain: why[type],
  };
}
```

- [ ] **Step 6: Write run**

`src/algorithms/dfs/run.ts`:
```ts
import { adjacency, edgeKey, vertexIds, type Graph } from '../../engine/graph';
import {
  treeEdgesFromPi, type Question, type Step, type Value, type VertexState,
} from '../../engine/trace';
import { DFS_MAIN, DFS_VISIT } from './pseudocode';
import {
  discoverQuestion, EDGE_LETTER, edgeTypeQuestion, finishQuestion, type EdgeType,
} from './questions';

type EmitOptions = {
  bigStep?: boolean;
  vertices?: string[];
  edges?: string[];
  note?: string;
  question?: Question;
};

export function runDfs(g: Graph): Step[] {
  const V = vertexIds(g);
  const steps: Step[] = [];
  const st: VertexState = {};
  for (const v of V) st[v] = {};
  const types: Record<string, EdgeType> = {};
  const stack: string[] = ['DFS(G)'];
  let time: number | undefined;
  let frame: Record<string, Value> = {};

  const emit = (proc: string, line: number, o: EmitOptions = {}) => {
    const edgeLabels = Object.fromEntries(Object.entries(types).map(([k, t]) => [k, EDGE_LETTER[t]]));
    steps.push(structuredClone({
      proc,
      line,
      bigStep: o.bigStep ?? false,
      vertexState: st,
      vars: { ...frame, time },
      ds: [{ kind: 'stack' as const, name: 'Call stack', items: stack }],
      highlight: { vertices: o.vertices, edges: o.edges, treeEdges: treeEdgesFromPi(g, st) },
      edgeLabels,
      note: o.note,
      question: o.question,
    }));
  };

  // Lecture, "Classification in real-time": decided by v's color when (u, v) is explored.
  const classify = (u: string, v: string): EdgeType => {
    const c = st[v].color;
    if (c === 'white') return 'tree';
    if (c === 'gray') return 'back';
    return (st[u].d as number) < (st[v].d as number) ? 'forward' : 'crossing';
  };

  const visit = (u: string) => {
    stack.push(`DFS_Visit(G, ${u})`);
    frame = { u };
    time = time! + 1;
    emit(DFS_VISIT, 1, { vertices: [u] });
    st[u].d = time;
    emit(DFS_VISIT, 2, { bigStep: true, vertices: [u], note: `${u} is discovered at time ${time}.` });
    st[u].color = 'gray';
    emit(DFS_VISIT, 3, { vertices: [u] });
    for (const v of adjacency(g, u)) {
      frame = { u, v };
      const key = edgeKey(g, u, v);
      const hl = { vertices: [u, v], edges: [key] };
      const isWhite = st[v].color === 'white';
      emit(DFS_VISIT, 4, {
        ...hl,
        question: isWhite
          ? discoverQuestion(v, `${v} is the next white vertex in G.Adj[${u}], so DFS_Visit(G, ${v}) is called.`)
          : undefined,
      });
      let note = `${v}.color is ${st[v].color}.`;
      let question: Question | undefined;
      if (types[key] === undefined) {
        const t = classify(u, v);
        question = edgeTypeQuestion(u, v, t, st[u].d as number, st[v].d as number | undefined, g.directed);
        types[key] = t;
        note += ` (${u}, ${v}) is a ${t} edge.`;
      }
      emit(DFS_VISIT, 5, { ...hl, note, question });
      if (!isWhite) continue;
      st[v].pi = u;
      emit(DFS_VISIT, 6, hl);
      emit(DFS_VISIT, 7, hl);
      visit(v);
    }
    frame = { u };
    st[u].color = 'black';
    emit(DFS_VISIT, 8, { vertices: [u] });
    time = time! + 1;
    emit(DFS_VISIT, 9, { vertices: [u], question: finishQuestion(u, time) });
    st[u].f = time;
    emit(DFS_VISIT, 10, { bigStep: true, vertices: [u], note: `${u} is retracted at time ${time}.` });
    stack.pop();
  };

  for (const u of V) {
    frame = { u };
    emit(DFS_MAIN, 1, { vertices: [u] });
    st[u].color = 'white';
    emit(DFS_MAIN, 2, { vertices: [u] });
    st[u].pi = null;
    emit(DFS_MAIN, 3, { vertices: [u] });
  }
  frame = {};
  time = 0;
  emit(DFS_MAIN, 4);
  for (const u of V) {
    frame = { u };
    const isWhite = st[u].color === 'white';
    emit(DFS_MAIN, 5, {
      vertices: [u],
      question: isWhite
        ? discoverQuestion(u, `${u} is the next white vertex of G.V in label order, so DFS_Visit(G, ${u}) is called.`)
        : undefined,
    });
    emit(DFS_MAIN, 6, { vertices: [u], note: `${u}.color is ${st[u].color}.` });
    if (!isWhite) continue;
    emit(DFS_MAIN, 7, { vertices: [u] });
    visit(u);
  }
  return steps;
}
```
